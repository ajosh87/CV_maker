# CV Tailor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local Flask + LangGraph app that turns a CV and a list of LinkedIn job URLs into ATS-safe DOCX CVs using only confirmed facts, with paste fallback and per-job clarification questions.

**Architecture:** Flask is a wizard; LangGraph runs one checkpointed thread per job; SQLite stores one master profile and all runs; an injectable `ChatModel` does language work; honesty filtering is deterministic code after the model.

**Tech Stack:** Python 3.11+, Flask, langgraph, langchain-core, python-docx, pdfminer.six, httpx, python-dotenv, pytest, sqlite3 (stdlib).

## Global Constraints

- Python 3.11 or newer.
- No LinkedIn login, cookies, passwords, browser profiles, or third-party scrapers.
- HTTP GET for job URLs uses a standard browser User-Agent only.
- LinkedIn HTML parsing fails closed (empty text → `needs_paste`); never use the whole page as the job description.
- One master profile; v1 is single-user local.
- Questions are per job; maximum 8; skip writes nothing.
- Rewrite/letter may use only profile after `apply_answers`; JD is keywords/order only.
- Output is DOCX only (Calibri, heading styles, no layout tables, no text boxes, no headers/footers).
- Cover letter only if `generate_letter` is true for that job.
- Unreadable CV: stop batch, create no runs.
- LLM unset message is exactly `set provider in .env`.
- One job LLM failure marks that run `failed`; other jobs continue.
- Export failure keeps structured draft on the run; do not write a fake DOCX.
- No live LinkedIn in tests.
- Package root import name: `cv_maker`.
- Data dir: `data/` (`cv_maker.sqlite`, `uploads/`, `output/`).

```python
from pathlib import Path
from pdfminer.high_level import extract_text as pdf_extract
from docx import Document


class UnreadableCvError(Exception):
    pass


def extract_text(path: Path) -> str:
    suffix = path.suffix.lower()
    try:
        if suffix == ".pdf":
            text = pdf_extract(str(path)) or ""
        elif suffix in {".docx"}:
            doc = Document(path)
            text = "\n".join(p.text for p in doc.paragraphs)
        else:
            raise UnreadableCvError(f"unsupported type: {suffix}")
    except UnreadableCvError:
        raise
    except Exception as exc:
        raise UnreadableCvError(str(exc)) from exc
    if not text.strip():
        raise UnreadableCvError("empty CV text")
    return text
```
